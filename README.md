# Peek 👀

캐릭터 카드를 한국어로 번역해서 보여주는 SillyTavern 확장. 실제 카드 데이터는 안 건드리고, 카드 아래에 번역 결과만 띄워줘.

## 특징

- 🔒 **카드 안 건드림** — description, first_mes 등 원본 그대로. RP에 영향 0
- 🔌 **연결 프로필 사용** — 메인 API랑 별도로, 번역 전용 모델(예: 빠르고 싼 거) 따로 지정
- 💾 **저장됨** — 번역 결과가 캐릭터별로 저장되어 새로고침해도 안 날아감
- 🔍 **저장된 번역 검색** — 캐릭터·페르소나 번역 버튼 옆에서 이름, 파일명, 번역 내용으로 검색하고 미리 본 뒤 자동번역 칸에 불러오기
- ✏️ **자동번역 수정** — 각 칸의 복사 버튼 옆 수정 버튼으로 편집·저장·취소
- 📂 **필드 선택** — description / personality / scenario / first_mes / mes_example / creator notes 중 원하는 것만
- 🎨 **카드 아래 표시** — 캐릭터 편집 패널 바로 아래 접이식 영역

## 설치

SillyTavern → Extensions → Install Extension → 이 GitHub 레포 URL 붙여넣기.

## 사용법

1. **연결 프로필 만들기** (없으면): SillyTavern의 Connection Manager에서 번역용 API 프로필 생성. Gemini Flash나 Claude Haiku처럼 빠르고 싼 모델 추천.
2. **확장 패널 열기**: Extensions 탭 → Peek 👀 펼치기.
3. **프로필 선택** → **번역할 필드 체크** → **번역하기** 클릭.
4. 확인창 뜨면 OK. 잠시 후 캐릭터 카드 아래에 번역 결과가 뜸.

## First Message에서 그리팅 번역 관리하기

1. 캐릭터 카드를 열면 일반 번역과 메모 사이에 **First Message**가 보여요. 번역이 아직 없으면 흐린 제목 줄의 **+**를 눌러 펼쳐요.
2. **기본**은 원래 첫 메시지, **ALT 1**, **ALT 2** 등은 카드의 대체 그리팅이에요. 번호가 많으면 옆으로 스크롤하거나 화살표를 눌러요.
3. API로 번역하려면 Peek 설정에서 기본 메시지는 **First Message**, 대체 그리팅은 **ALT 전체 번역**을 선택한 뒤 캐릭터 시트의 👀 버튼을 눌러요.
4. 다른 곳에서 번역한 본문을 쓰려면 번호를 고르고 **+ 번역 추가**를 눌러 붙여넣은 뒤 **저장**해요. 자동번역 옵션을 체크하지 않아도 돼요. 직접 넣은 번역은 번호 옆에 점이 생기고, 본문 헤더에 **직접 추가**로 표시돼요.
5. 자동본과 직접 추가본이 둘 다 있으면 직접 추가본이 먼저 보여요. **자동본 보기**와 **직접 추가본 보기**로 전환할 수 있어요. 두 번역은 별도로 저장돼요.
6. 원본 카드에 없는 그리팅을 만들려면 **+ 새 그리팅**을 눌러요. **추가 1 · 직접 작성**처럼 Peek에만 저장되며, 실리태번의 실제 스와이프 번호는 생기지 않아요.

## 스와이프 목록에서 번역 적용하기

### 설정과 이동

1. **Extensions → Peek**에서 **채팅에 그리팅 번역 표시**를 켜요. 이 옵션을 켜면 실제로 적용한 번역을 채팅 본문에서 볼 수 있어요. **그리팅·스와이프 목록에 번역 표시**는 미리보기만 바꾸는 별도 옵션이에요. 두 옵션 모두 처음에는 꺼져 있어요.
2. 캐릭터의 첫 채팅 메시지에 스와이프가 여러 개 있으면 PC에서 번호를 클릭하거나 모바일에서 번호를 길게 눌러 실리태번 스와이프 목록을 열어요.
3. 목록에서 항목을 누르거나 번호 칸에 번호를 입력해요. 번호 칸 옆에서 연결 상태를 확인하고 **번역 적용** 또는 **연결 확인**을 눌러요. 연결 확인에서는 **현재 원문**과 **저장된 번역**을 비교한 뒤 **이 원문에 연결**을 눌러요.
4. **Go**를 누르면 실리태번이 그 번호로 이동해요. 이미 그 번호에 있다면 적용 즉시 본문이 바뀌어요. 번역은 실리태번의 채팅 본문 서식으로 표시되며 AI에는 원문이 전달돼요. 기존 번역을 표시할 때는 모델 API를 호출하지 않아요.
5. 적용 여부는 채팅과 스와이프별로 저장돼요. 목록을 다시 열어 같은 번호의 **번역 해제**를 누르면 원래 표시로 돌아와요. 설정을 끄면 적용 기록을 보관한 채 채팅 화면에서 번역 표시를 중지해요.

### 연결 상태

| 라벨 | 뜻 | 할 일 |
| --- | --- | --- |
| 원문 일치 | 저장 시 기록한 원문이 현재 스와이프와 일치해요. 순서가 바뀌어도 원문으로 찾을 수 있어요. | 자동본은 바로 적용할 수 있어요. 직접 추가본은 처음에 두 본문을 확인해요. |
| 원문 변경 | 저장 당시의 원문과 현재 원문이 다르거나, 이전에 연결한 뒤 스와이프 원문이 바뀌었어요. | 두 본문을 확인한 뒤 연결해요. |
| 원문 기록 없음 | 저장본에 비교할 원문 정보가 없어요. | 두 본문을 확인한 뒤 연결해요. |
| 원문 중복 | 같은 원문을 기록한 번역 후보가 여럿 있어요. | 제안된 번역을 확인한 뒤 연결해요. |
| 직접 연결됨 | 두 본문을 확인하고 해당 번호에 연결했어요. | 필요하면 **번역 해제**를 눌러요. |

**원문 일치**는 원문끼리 비교한 결과예요. 번역문이 원문과 같은 뜻인지는 사용자가 확인해요. 연결 후 원문이나 번역문을 수정하면 이전 연결은 더 이상 적용되지 않아요. 번역 후보가 없는 번호에서는 실리태번의 **Go**를 그대로 사용할 수 있어요.

**목록에 번역 표시**를 켜면 갈 수 있는 스와이프에 연결된 번역이나 원문이 일치하는 번역을 미리 보여줘요. 대응하는 스와이프가 없는 번역과 **직접 작성** 그리팅은 **Peek에 저장된 그리팅**에서 읽고 복사할 수 있어요. 실제 스와이프가 한 개뿐이라 목록을 열 수 없는 경우에는 이 참고 목록을 첫 메시지 아래에 표시해요.

이 기능은 1:1 채팅의 첫 그리팅을 대상으로 해요. 다른 확장이 현재 메시지에 별도 표시본을 제공하면 그 표시가 우선해요. 번역 본문에서 `{{user}}`, `{{char}}`, `{{newline}}`은 표시할 때 치환하고, 나머지 매크로는 입력된 형태로 남겨요.

## 저장된 번역 불러오기와 수정

- 캐릭터 시트나 페르소나의 👀 옆 🔍를 누르면 같은 종류의 저장된 자동번역을 검색할 수 있어. 검색어가 없으면 전체 목록이 나와.
- 결과를 선택하면 필드별 전체 내용을 미리 볼 수 있어. **불러오기**를 누르면 현재 대상의 자동번역 칸에 저장돼. 기존 자동번역이 있으면 덮어쓰기 확인을 받아. 수동번역과 메모는 유지돼.
- 불러오기 전 자동번역은 별도 `peek_undo_*.json` 파일에 보관돼. 패널 하단 **되돌리기**로 마지막 불러오기 직전 상태를 한 번 복원할 수 있고, 새로고침 후에도 사용할 수 있어. 처음에 번역이 없었다면 빈 상태로 돌아가. 다시 불러오면 복원 지점도 그 직전 상태로 바뀌어.
- 되돌리기는 불러온 뒤 수정한 자동번역도 대체해. 수동번역과 메모, 원본 카드와 페르소나 설명은 건드리지 않아. 백업 파일을 저장하지 못하면 불러오기를 중단해 기존 번역을 보호해.
- 자동번역 칸의 ✏️를 누르면 해당 칸만 수정할 수 있어. **저장**하면 파일에 반영되고 **취소**하면 원래 내용이 유지돼. 캐릭터 카드와 페르소나 원문에는 영향을 주지 않아.
- 외부 검색이나 모델 API 호출 없이 저장된 결과만 사용해.

## 동작 원리

- `ConnectionManagerRequestService.sendRequest`로 선택된 프로필에 직접 요청 → 메인 채팅 컨텍스트, lorebook, 시스템 프롬프트 등 일절 안 섞임
- 번역·수동번역·메모와 직접 추가한 그리팅은 `/user/files/peek_*.json`에 대상별로 저장. `extension_settings.peek`에는 파일 인덱스와 UI 설정을 저장
- 파일 저장 실패 시 데이터 보호를 위해 기존 settings 저장 방식으로 전환. 예전 settings 데이터는 자동으로 지우지 않음
- 검색 목록과 편집 초안은 메모리에서만 관리하고 settings에 번역 본문을 중복 저장하지 않음
- 캐릭터 전환 시 자동으로 해당 캐릭터의 저장된 번역 불러옴
